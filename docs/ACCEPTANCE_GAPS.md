## Cross-project acceptance still missing

Cross-project fixtures now cover composed temporal graph values, real cyclic metadata, finite signed-evidence rules, exact contexts, geometry, pinned clustering, identity resolution and accepted graph reads. Compiled Query/Filter view artifacts execute through explicit native registration/refresh with freshness and current-policy checks. These are bounded implemented profiles, not full reasoning, arbitrary live queries, full authorization or distributed language conformance; the specific missing semantics are listed in the rows above.

The native three-peer experiment separately exercises offline evidence editing, trusted host reactions, portable history, conflict preservation and explicit governance acceptance. Its native handler code is not compiled reactor syntax or a mobile source-host test. The separate 0.18 source handler fixture now proves the compiled bridge through explicit native install/prepare/complete, pinned replay and controlled crash boundaries. Integrating that compiled bridge into the entire three-peer scenario, actual portable hosts and the remaining transport/release semantics is still required. Duplicate events, unavailable dependencies and current revocation must remain part of that combined acceptance; native capsule/process tests alone do not establish mobile conformance.

## Public-release readiness versus full-design completion

A public experimental GitHub source release can proceed with clearly documented gaps, MIT notices, reproducible source builds and passing public CI. It does not require pretending the full design is complete. The original requested project completion remains open until the relevant requirements pass their gates or the owner explicitly amends scope.

`cargo package`/crates.io publication is not the current distribution path: Cargo excludes nested package contents and strips path dependencies when packaging. This repository is marked `publish = false` until a coordinated optional registry release exists. Git clones and `git archive` include the standalone vendored contract and can build or install with `cargo install --locked --path .`. Do not describe a `.crate` package as self-contained.

The audit does not establish a minimum supported Rust version below the tested 1.94.0, browser runtime support from a WASM check, success on an unrun CI platform, or a configured private security-reporting channel. Those are explicit evidence gaps, not implied capabilities.
